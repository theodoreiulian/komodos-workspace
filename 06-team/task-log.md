# Task log

**Why this file exists:** we decided on 23 Sep 2026 to carry no standing
subject-matter roles — everyone works on everything, and work is assigned as
one-off tasks. That decision removes the easy evidence of division of labour
that a roles table would have given us. This file *is* that evidence, and
criterion 4 asks for it. See `06-team/working-model.md`.

**Rules:**
- Assign at the weekly meeting. Named person, dated. No unassigned tasks.
- Write the line when the task is assigned, not when it is finished.
- On completion, fill in **Done** and **Output** — a file, script, or
  decision-log entry. "Done" with no output is not done.
- Standing obligations (decision log, reproducibility check, rules check,
  trading note review) get reassigned **every week**, to different people where
  possible.
